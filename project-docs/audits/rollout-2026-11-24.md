## Notes

- All Bond trial buttons are Title Case, so `my` and `your` use Title Case on every surface, not a sentence-case onboarding variant.
- No new Swift files: `TrialCTA`, `RemoteSwitch` and `RemoteConfig` live in `Bond/Services/PurchasesService.swift`, because `xcodegen` is not available on this machine and `Bond.xcodeproj` is tracked. Moving them to their own file later needs `xcodegen generate`.
- Ask to Buy unlock path: `customerInfoStream` in `PurchasesService.bootstrap()` already unlocks without a relaunch. The plan screen and onboarding already reacted to `isPremium`. The trial sheet did not, so `PaywallFlowSheet` now closes when `isPremium` turns true (a dismissal, not a new paywall appearance).
- Stale pending state: it is view `@State` only (`awaitingApproval`, onboarding `isPendingPurchase`). Onboarding clears it on "Continue for free", so a later approval cannot finish setup a second time.
- The star prompt already fires only after marking a reminder done (Rollout S not run here, so it is unchanged apart from the switch).
- The Android port (`android/`) is not changed.
